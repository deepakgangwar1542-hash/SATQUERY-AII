# datasets/

- `samples/` — **shipped** synthetic bi-temporal scene pair + ground-truth
  change mask (generated by `scripts/make_sample_data.py`). Enough to run the
  entire system end-to-end with no downloads.
- `vrsbench/`, `levir-cd/`, `other/` — empty placeholders. Place downloads
  here and record their licenses in `LICENSES.md` (PRD §14.3). Nothing in
  this repo currently depends on them.

- BigEarthNet v2.0 → see `bigearthnet_module/BIGEARTHNET_README.md`
- LEVIR-CD → official project page (research-only license)
